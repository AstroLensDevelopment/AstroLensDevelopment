### Focus

Astronomy, astrophysics, spectroscopy, optics, scientific computing, atmospheric science, and data analysis — work that moves between telescope, terminal, and lab notebook. AstroLens exists to put that work in the open: raw signal in, calibrated science out.

<br>

### Research

| | |
|---|---|
| **AstroLens** | Open-source platform for astronomical spectroscopy — acquisition, reduction, and analysis in one pipeline. |
| **pySPEC** | Python toolkit for spectral reduction, calibration, and line identification. |
| **Atmospheric Profile Generator** | Models atmospheric transmission and absorption bands for ground-based spectral corrections. |
| **Telluric Correction Suite** | Removes atmospheric absorption from stellar and planetary spectra via synthetic transmission models. |
| **Optical Instrumentation** | Design and fabrication of low-cost diffraction-grating spectrographs. |
| **Spectroscopy Tools** | Wavelength calibration, continuum normalization, and spectral line analysis utilities. |
